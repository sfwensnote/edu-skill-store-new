2026-10-10。用户明确要求清空 Demo 集市以及“我的作品”里现在所有 SKILL。本批基于已发布的 `5264ad4`，按既有授权检查后直接上传并通过 GitHub Actions 发布。

## 清理范围

- 默认五项集市方法和六个试用案例移出正式前端，列表从空开始。旧样例仅作为隔离测试资料保留，不进入生产构建。
- 新版首次启动时移除个人方法、创建草稿、已添加的来源快照、核对记录、排除记录和旧恢复副本。
- 同时解除现有 SKILL 收藏、分享、旧方法任务和挂载引用；清理集市与我的 SKILL 的旧筛选缓存。
- 保留无关浏览器资料、旧非 SKILL 设计和学习记录；后台数据库未改动。

一次性完成标记为 `teaching-method.skill-reset.2026-10-10.v1`。标记写入成功后才启动应用，后续刷新和发布保留新建内容。存储失败时尝试恢复已改动数据，显示重试入口，不启动应用继续写入新资料，也不假报清理完成。以后不得通过修改标记重复清空教师的新内容。
