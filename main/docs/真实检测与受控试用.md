# 真实检测、受控试用与回收报告

2026-10-11。本批沿用原绿色界面，替换原手动确认式检测；首页、集市布局和个人资料存储键不变。

## 已实现

- 方法检测：模型生成覆盖触发、不触发、各步骤、各原则和结束条件的情境，真实执行并逐项核验。记录实际输入、回复、触发判断、四项结果和逐字引用。失败、证据不足或覆盖不完整不能通过；教师查看后确认，才获得验证资格。
- 挂载门槛：验证绑定方法内容、模型地址和模型名称。修改方法或更换模型后重新检测。前端状态、旧“教师已核对”标签不能绕过服务端检查；集市只读添加项可以检测，不取得修改权。
- 学伴试发布：保存场景、已验证方法及实际解析的材料快照。教师自行试用与学生使用同一执行逻辑。链接限制1至30人、1至168小时；可以结束、撤销或轮换邀请链接。已进入的学生有独立凭据，重复进入及重试不额外占名额。教师自行试用不计入学生报告。
- 回收报告：结束后后台分析学生记录，分为学生学习表现、方法执行、学伴问题。每项引用可打开完整对话；服务器校验编号和原文。保留实际请求异常，包括失败后重试成功的异常。教师记录符合预期、调整场景、修改方法或扩大试用的意见。扩大使用仍需要教师开启新一轮受控试用，不自动向所有学生开放。
- 检测和报告任务离开页面后继续。服务重启会将中断任务标为失败，保留已取得的消息，不伪造完成。

报告固定注明：仅凭对话记录不能认定学习效果提升。模型判断也不是学习成效评价，教师必须结合具体证据核对。

## 代码与数据

`shared/execution.ts` 定义闭环契约。`server/execution/` 按记录、执行、检测、试用、报告、任务队列和接口分工；`src/features/execution/` 承担相应页面和 API 调用，不继续堆入旧检测组件。移除旧 TestingPage、案例确认和检测内方法编辑组件及专用样式。

真实运行启用服务端教师／管理员身份。密码保存 scrypt 摘要，登录与学生凭据在数据库中保存摘要；公开学生接口仅限所属试用，教师接口按账号隔离。生产环境不生成固定样例账号；迁移来的已知样例账号停用但保留资料。管理员只能由部署管理员创建。已有昂贵旧模型接口增加认证。

SQLite 增量增加真实执行记录和凭据表，不覆盖旧教师数据库。试用快照与对话不随浏览器修改方法改变。原 SKILL／学伴编辑工作区、收藏、集市和附件原件仍按账号存在浏览器，**本批没有宣称整套工作区或集市已经跨设备同步**；服务端持久化覆盖身份、方法检测、试用快照、实际交互和报告。浏览器工作区删除不删除服务端证据；有开放试用时先结束再删除。删除后历史快照保留在教师接口，专用归档列表尚未加入。

支持 TXT、Markdown、可提取文字的 PDF 和 DOCX；材料在服务器实际解析后进入上下文。图片及扫描件需先转文字，不把附件名称当作模型已经理解材料。

## 部署

模型中转不是本项目后端。GitHub Pages 仍只提供静态网页，无法保存学生跨设备交互或保护密钥。

推荐在一台确定的服务器上同源部署：

1. 在 `main/` 复制 `.env.example` 为私有 `.env`，填写模型 URL、名称、密钥及 `WORKSHOP_DOMAIN`。用户选定模型是 `deepseek-v4.1-flash`；同一模型可同时配置 DESIGN 和 TEACHING。密钥不得填入 VITE 变量、仓库、网页或公开日志。
2. 将域名解析至本项目服务器，开放80／443。`docker compose up -d --build` 启动网页、Node 24 后端与 Caddy HTTPS；数据库使用独立持久卷。保留数据库及其备份，禁止用 `docker compose down -v` 清除正式数据。
3. 私有环境中设置 `ADMIN_PASSWORD`，执行 `npm run admin:create -- 账号 姓名`。容器方式先把该变量传入执行环境，再运行 `docker compose exec -e ADMIN_PASSWORD workshop npm run admin:create -- 账号 姓名`。不存在公开的默认管理员密码。
4. 单实例运行本项目后端；后台模型任务是该进程内的有界队列。多实例部署需要另行实现共享任务调度。

如果继续保留 Pages：服务端 `FRONTEND_ORIGINS=https://sfwensnote.github.io`；GitHub 仓库 **Variables** 设置 `API_BASE_URL` 为本项目 HTTPS 后端根地址，然后重新运行 Pages Actions。这个地址不是模型中转 URL。仅设置公开后端地址，模型密钥只留在后端。独立后端登录使用当前标签页的服务端凭据；旧本机账号不会变成服务端身份，旧资料不会被删除。

HTTP 中转默认拒绝。优先使用中转方提供的 HTTPS；可信内网确需 HTTP 时，由部署管理员显式配置 `ALLOW_INSECURE_MODEL_HTTP=true`，明确接受后端到中转这一段的明文传输。

- 类型、源码引用、Pages 子路径构建通过。正式容器构建并核验网页、真实注册、重启后数据库保留以及无模型配置时阻止运行。运行依赖已修补可兼容告警；生产审计仍有3项 moderate，均由 mammoth 的 CLI 参数依赖链引起，服务器使用 rawText API，不执行该 CLI。开发工具还有7项 high 无兼容补丁；未强制降级 shadcn 或 Word 解析器。

- 用户尚未指定或接入本项目后端部署服务器／平台。Pages 发布不等于后端已上线；未连接后端时清楚显示连接原因，禁用真实检测和新挂载，不退回样例冒充验证。

后续上线验收必须使用已批准访问的实际中转，并由教师核对完整情境、多轮结束、材料理解、少量学生交互与报告质量。
