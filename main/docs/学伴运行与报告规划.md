# 学伴运行与报告规划

日期：2026-10-13。状态：本批前端实现完成；验证记录见《师说交互与视觉验收》。

参考 `images/学伴详情页.png`、`images/我的报告.png`。沿用师说现有导航、深绿主题、宋体标题与黑体正文，不建立第二套页面外框。用户已确定发布弹窗可以设置运行时长，用户最后明确停止 Worker、不使用技能，由主 Agent 完成实现。

## 流程和跳转

| 位置 | 操作 | 结果 |
| --- | --- | --- |
| 学伴详情顶部及底部 | 试运行 | 进入现有独立学伴试运行页，保留当前场景、历史、刷新与结束行为 |
| 学伴详情顶部及底部 | 运行 | 打开运行发布弹窗，展示学伴与已添加教学方法，设置 1～168 小时 |
| 运行弹窗 | 发布 | 沿用当前账号的 `/trials` 前端接口，保存成功后进入该学伴运行报告；失败保留时长、显示原因、不跳转 |
| 运行弹窗 | 未核对或场景不完整 | 给出完善学伴、前往教学方法验证入口；不伪造发布资格 |
| 报告页 | 返回学伴 | 返回对应学伴详情；不丢失学伴或运行记录 |
| 报告页 | 再次运行 | 使用当前学伴打开新的运行配置；确认发布后保存新快照，保留旧记录 |
| 报告页 | 查看对话 | 弹窗展示所选记录的原文与角色，关闭恢复原行焦点 |
| 报告页 | 切换运行记录、搜索、排序 | 筛选当前学伴的实际记录，清除筛选可恢复；没有匹配项提供明确空态 |
| 报告页 | 下载报告 | 导出当前报告的可读内容，排除身份凭据、模型配置及材料原始数据；无记录时仍可导出空态说明 |

已新增 `#/companions/<id>/report`，可用 `run` 查询参数选择记录。此页仍高亮“我的学伴”，不新增一级导航。失效学伴或运行记录显示可返回的空态，不能冒用其他学伴资料。

报告中的试运行入口继续采用原独立试运行流程；它会保存独立的当次场景和方法快照。由报告进入试运行时，返回地址使用不固定 `run` 的同学伴报告地址，返回后只展示最新的运行记录；试运行独立保留历史，不进入运行报告统计。

## 数据边界

本轮仍只做前端，不部署后端、调用真实模型或开放学生链接。复用 `teaching-method.execution-preview.v1:<accountId>` 中已有运行与对话，不更换资料键或一次性清理标记。运行发布沿用现有快照、核对与保存失败保护。

- 教学方法触发数来自实际记录的 `RecordedMessage.activations`，方法名称读取运行快照。
- 对话数、回复数、时间与状态来自当前学伴的 `Trial`、`TrialSession`；不把教师对话计为真实学生数量。
- 时长使用实际消息 `at` 的首尾跨度，明确称为对话时长；不足两条有效时间时不填造数字。
- 任务完成度尚无明确结果资料时显示待记录。结束条件标记、关闭对话和学生掌握程度互相独立，不能互相替代。
- “饱和度”等尚未定义的指标不分箱造数；相同位置优先展示可追溯的方法使用频次。
- 不照抄参考图的 168、77%、增长率或学习效果。无可比历史时显示暂无可比记录。
- 表格与对话仅使用所属账号、对应学伴记录。数据读取失败显示重试，不将失败当成空数据成功。

## 展示与动效

详情保留学习场景／教学要求左栏、已添加方法／材料右栏及底部操作区；顶部按钮通过外层容器定位，避免再次与悬停位移冲突。背景只作用于此详情／报告页头，其他内容页保持已有背景。

报告采用上方标题与操作、两张统计卡、三块图表、下方记录表格。图表与表格使用现有绿色层次，条目悬停轻微提亮，图表有数值提示和键盘可访问的文本说明，排序和展开反馈清晰。进入与展开动效短暂、克制，减少动画偏好时停用位移动效。手机卡片单列，表格只在自身容器滚动。

## 实现边界和验收

发布弹窗、报告统计、报告展示按独立文件分工；主 Agent 接入路由与详情，再安排独立只读审查。单元检查覆盖空数据、实际触发、时长、历史快照与不变更原资料；浏览器检查覆盖时长、发布成功／失败、报告刷新、对应学伴返回、再次运行、筛选、对话、下载及 320px 无溢出。

首批模块合同：

- `CompanionRunDialog` 接收 `value`、`skills`、`onClose`、`onPublished(trial)`、`onCheck(entry)`、`onEdit`，不自行修改全局路由。最多 168 小时，保存前校验场景与原资格；前端发布复用 `/trials`，不扩展真实 server 入口。
- `companion-run-metrics.ts` 导出 `CompanionRunDetail`（`trial` 和 `sessions`）及 `buildRunMetrics(details, now?)`。结果包含实际 `activationCount`、`assistantTurns`、`conversationCount`、`methodUsage`、`durationTrend` 和对话 `rows`；不生成任务完成百分比或学习效果评分。
- 每条 `rows` 包含 `sessionId`、`trialId`、`name`、`audience`、`createdAt`、`messageCount`、`assistantTurns`、`activationCount`、可为空的 `durationSeconds`、`status`（`running/ended/revoked/expired`）、`endingObserved` 和原 `messages`。不修改输入快照；未知／无有效时间不填造时长。
- `CompanionRunReportPage` 接收 `value`、可选 `trialId`、`onBack`、`onRun`、`onPractice`。只读当前学伴记录，读取失败保留可重试状态，展示和导出都采用上述统计与原文。

派发容量沿用当前会话实际限制，先并行发布弹窗与统计模块，再接入依赖统计的报告展示。Worker 服务失败不计交付，不换模型；用户已明确选择等待 DeepSeek 恢复。
