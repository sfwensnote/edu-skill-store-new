# 教学 SKILL 产品重设计与 Demo

日期：2026-10-10。以本轮用户讨论为准；已确认先完成检测与发布流程 Demo。

## 已确认的方向

核心价值是把教师经验整理成可复用的教学 SKILL。同一份方法供教师阅读、采用，也用于描述 AI 应遵守的教学判断。

Demo 默认已有检测模型；LLM 只在作者检测工作区参与，不进入整理、集市或挂载后的运行。使用者下载 SKILL 后自行挂载到选定平台，本产品不提供集市预览或在线体验。本轮不接真实模型接口，检测返回使用明确标注的演示数据。

PBL、情境题、任务链和学生任务暂时搁置，不进入新 Demo 的主导航。旧代码、路由和浏览器资料保留，通过页脚的旧版作品入口查看。

## Demo 的唯一主流程

教师经验 → 整理 SKILL → 教师核对 → LLM 检测 → 发布到集市 → 使用者下载并自行挂载。

整理工具不是完成标准。教师可以借助预设问题逐步填写，也可以直接编辑完整方法；不要求必须回答六问。系统不从一句经验编造整份方法。

| 页面 | 教师完成的任务 | 产出 |
| --- | --- | --- |
| 我的 SKILL | 新建、继续草稿、查找已有方法 | 同一浏览器保存的 SKILL 与草稿 |
| 整理 | 记录经验、补充目标、输入条件、条件与做法、原则、介入边界 | 独立 SKILL 的内容版本 |
| 核对 | 对照内容逐项确认教学意图 | 绑定当前内容版本的教师核对记录 |
| LLM 检测 | 设置测试输入，查看模型回答与检测意见，处理未通过情况 | 绑定版本与内容签名的检测记录 |
| 发布 | 确认当前版本已核对并检测通过 | 当前版本的本机演示发布状态 |
| SKILL 集市 | 查看方法说明、下载 SKILL.md，自行挂载；也可复制到创作工作区修订 | 发布内容与挂载指引，无预览或模型运行 |

## 从源头调整数据归属

SKILL 不再嵌套于助手。新数据模型使用独立标识、教学内容、来源、版本、教师核对记录。

- 草稿保存正在填写的经验、问答及手动修订，未提交回答也保留。
- 形成的内容版本是阅读、核对和下载的共同来源。
- 草稿发生修改时，原内容版本仍可查看，界面明确提示有待形成的修改。
- 内容变化并形成版本后，版本递增；该 SKILL 的旧核对、检测与本机发布状态失效，新版本需重新核对和检测。
- 没有内容变化时不制造新版本，不影响其他 SKILL。
- 复用保留来源，但不继承教师核对、检测或发布状态；修改副本不改写来源。
- 每个教学分支和信息不足情境都必须完成检测；有未通过情境不能发布。重新检测及修改测试输入会撤回旧检测和本机发布状态。

草稿和内容版本是编辑与使用两个阶段，不是两套各自维护的教学方法。检测指令、集市说明和挂载文件均从同一份已形成内容派生。

新资料使用 teaching-skill.workspace.v1。旧版 teaching-assistant.frontend-demo.v2 等存储不清空、不自动覆盖；旧版资料仍从兼容页面读取。新旧数据的批量迁移尚未实现。

## 教学方法的最小内容

名称与分类、学段与学科、经验来源、教学问题、学习目标、开始条件、条件分支与具体行动、教学原则、使用前所需信息、不适用或需要教师介入的情况。

缺少名称、分类、目标、开始条件、完整条件与行动、原则或使用边界时不能形成 SKILL。问答内容不得覆盖教师已经手动编辑的字段。

## 创作检测与集市分工

作者完成教师核对后进入 LLM 检测，查看每个情境的测试输入、预期行为、模型回答及检测意见。支持演示模型按方法回答，以及信息不足时越界两种返回；全部情境通过才可继续发布。有问题的版本回到编辑处修订。

本轮检测为 Demo，界面标明模型已接入（Demo），每条回答和检测意见标为演示。它用于验证产品流程，不构成真实模型执行或学习效果证据。没有调用付费模型，没有将演示失败降级成通过。

集市只展示教学问题、目标、开始条件、条件与行动、原则、输入要求、使用边界、来源及版本；不显示检测对话，不提供聊天、预览或在线运行。原 AI 预览地址兼容为纯说明页，不恢复体验入口。

使用者下载 SKILL.md，按目标平台支持的文件、指令或技能配置方式自行挂载，并补充教学材料与上下文。挂载文件包含名称、描述、版本和完整教学方法；格式是否兼容及实际执行效果须在目标平台验证。

发布为当前浏览器内的集市演示，不将资料上传到公网或更新 GitHub Pages。检查存储成功后才显示已发布。

## 视觉与交互方向

延续现有设计：背景 #f5f6f4，白色 #ffffff，文字 #192d27，主色 #25634f，浅绿 #eef5f1，边框 #dee5e0。字体继续使用苹方、微软雅黑及系统无衬线字体；标题 28px，章节 18–22px，正文 14–15px。

左对齐，内容优先。首页以一个课堂判断示例引出主流程；作品采用方法列表，避免用统计卡片填充首页。编辑页复用已有方法编辑组件，核对页将内容与核对清单对应，检测页展示逐情境输入与结果；发布页显示核对、检测和发布条件；集市详情是独立的只读说明。

审视初稿后，去掉重复创建按钮与重复确认动作，Demo 的推荐标签不夹带 PBL 或任务链入口。320px 手机、键盘焦点与保存失败保护纳入验收。

## 实现位置与兼容

- shared/skill-workspace.ts、skill-detection.ts：独立 SKILL、版本、核对、检测与发布规则、复用和挂载文件。
- src/features/skills：作者整理／核对／检测／发布、集市说明、示例与本机持久化；demo-detection.ts 模拟检测返回。
- src/RootApp.tsx：首页及新 SKILL 路由进入 Demo；旧路由继续载入原应用。
- src/features/designer：继续复用经验表单、问答和方法编辑能力，只增加可选配置。

旧助手、PBL、任务与后端模块没有删除。新主流程不依赖这些对象。保留兼容入口是资料保护措施，后续可在确认迁移范围后清理代码。

## 下一轮应通过 Demo 判断什么

教师能否从课堂片段写清条件、行动和边界；检测情境能否发现含糊与越界；发布条件是否清楚；使用者能否仅凭说明与文件完成自行挂载。

真实检测接口、集市服务端存储、多人协作与跨设备同步后续再接入。2026-10-10 用户已授权将本轮 Demo 更新提交到仓库，并通过 GitHub Actions 发布静态前端到 Pages；实际部署结果以对应提交的 Actions 记录为准。网站上线不改变 SKILL 发布保存在当前浏览器的演示边界。

## 验证与查看

本轮验证完成：73 项单元／集成检查、10 个 SKILL 浏览器场景全部通过。覆盖独立版本与检测签名、发布条件、修改后状态失效、检测未通过禁止发布、浏览器存储失败不显示成功、集市无预览、文件下载和 320px 手机布局。

生产构建使用 `/edu-skill-store-with-pbl/` 子路径并通过检查：10 个新旧路由与资源可加载，完整走通复用 → 核对 → 检测 → 发布 → 集市说明，刷新后发布状态仍保留，390px 手机页面无横向溢出。`git diff --check` 通过。这些是本地构建验证，不代表已部署至线上。

本机可从 main/ 执行 `npx vite --host 127.0.0.1 --port 5173`，打开 `http://127.0.0.1:5173/#/home`。在集市查看说明并“复用到我的工作区”，可以最快走完整理 → 教师核对 → 检测 → 发布；也可从“创建 SKILL”录入自己的经验。此命令只启动静态前端，不启动数据库或 Express。

旧版页面仅检查路由与资源兼容，未重跑此前 43 项旧版浏览器基线。旧集市保留在 `#/legacy-market`，`#/market` 是新的无预览集市；既有浏览器资料不清空。
