# 界面统一与 SKILL 图标验收

日期：2026-10-11。沿用原前端，本批整合用户追加的学伴页面、预览位置、重复组件清理、视觉统一和 SKILL 图标要求。

## 已完成

- 我的学伴沿用绿色机器人插画，卡片使用已选头像和实际保存的信息。学习场景、SKILL、材料分区展示；支持搜索、状态／学科筛选、排序、查看、编辑、复制为草稿及确认删除。不添加样例，不提供列表上传材料按钮。
- 查看草稿也进入详情；继续创建才进入编辑。复制只新增学伴草稿，保留原方法引用。复制或删除写入失败时不改变已保存内容，恢复存储后可重试。
- 最后一步学伴预览在上、预览与保存在下；前三步不渲染预览。详情使用教师选择的形象，桌面分栏、手机单列。
- 我的 SKILL 顶部三张统计卡及独占代码、样式移除；全部／我创建的／从集市添加分类保留在侧边，手机使用原分类选择框。
- 标题与顶部区域统一由 `src/styles/page-layout.css` 管理。桌面标题 36 px、手机 28 px，内容最大宽度 1460 px，页面外框与导航对齐；顶部内容区域最小高度 176／144 px，长标题可自动增加高度。背景共用首页浅绿色渐变，固定到视口，避免不同页面长度改变配色位置。被替代的各页标题与统计卡样式已清理。

## 图标保存与同步

图案映射集中在公共 `SkillIcon` 组件：课堂提问、错因辅导、智能练习、知识讲解各有一个固定图案，未分类旧资料使用兼容图案。创建的初步想法与方法编辑均可调整颜色、上传图标或恢复分类图案。图片只接受 1 MB 以内 PNG、JPG、WebP，实际解码检查后保存；读取失败不替换原图标，手机上传控件不产生横向溢出。

图标存入原 `EducationalSkill.icon` 可选字段，包含颜色与图片。草稿、方法封装、重新编辑、检测内修改和发布保留该字段，集市与我的 SKILL 共用同一显示组件。其他教师添加时保留图标的只读来源快照，不取得修改权限；原作者之后更改图标不覆盖已添加的快照。旧资料没有该字段仍能读取和展示。没有建立第二套工作区或清理教师资料。
