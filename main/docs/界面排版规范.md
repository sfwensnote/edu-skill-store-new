# 界面排版规范

在现有结构与配色上统一，不改业务流程。

- 页面标题：桌面 28px，窄屏 24px；分区标题 20px。
- 正文：14–16px；辅助文字 13px。字体沿用系统无衬线字体。
- 间距：8px 用于紧邻元素，16px 用于字段与内容，24px 用于分区，32px 用于桌面页面起始留白。
- 常规按钮最小高度 40px，主操作 44px；窄屏筛选及主要图标按钮提供 44px 点击区域。
- 按钮使用一致的悬停、按下、键盘焦点和禁用反馈；禁用按钮不产生按压位移。
- 尊重系统减少动态效果设置，保留长按钮文案换行能力。

设计变量在 `src/styles/tokens.css`，交互基础规则在 `src/styles/base.css`。
