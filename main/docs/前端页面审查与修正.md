# 前端页面审查与修正

2026-10-09。沿用现有深绿色、浅灰绿和白色工作台，检查主要页面的排版、表单、弹窗、焦点与窄屏操作。仅修改本地前端及对应检查，不接入后端服务。

## 已修正的问题

| 页面 / 问题 | 修正 |
| --- | --- |
| 手机作品页连续出现两层搜索和完整筛选，列表被推到很下面 | 默认显示当前分类搜索；跨分类搜索有内容时继续显示，避免隐藏有效条件；筛选可展开，收起后显示有效条件数量。概览卡片压缩高度。 |
| 手机操作图标过小，部分按钮换行不协调 | 更多操作、关闭、发送等图标按钮调整为至少 44 × 44px；菜单项保留 44px 高度；作品操作文字保持一行。 |
| 手机部分下拉框仅 12–13px | 主要输入控件统一为 16px，保留标题、说明和按钮各自的文字层级。 |
| 公共弹窗没有统一屏高上限，表单样式与页面不一致 | 按动态视口限制高度，长内容在弹窗内滚动；标题避让关闭按钮；表单沿用公共颜色、边框与焦点样式。 |
| 从更多菜单打开弹窗，关闭后焦点落在已经移除的菜单里 | 记录原操作按钮，关闭弹窗后恢复焦点；删除原作品后回到页面内容。 |
| 从长列表进入详情仍处于旧滚动位置，键盘继续操作导航栏 | 新页面回到内容顶部并聚焦主内容；集市与作品列表仍恢复各自的浏览位置与筛选；增加仅聚焦时显示的“跳到页面内容”入口。 |
| 活动切换步骤后停留在旧位置，错误提示可能在视野之外 | 新步骤定位活动配置区，校验失败时定位可读的错误提示。 |
| 手机端隐藏保存反馈，最后的内容可能被固定操作栏遮住 | 保留保存状态，测量操作栏实际高度并同步更新页面底部留白；步骤、状态和屏宽变化时重新计算。 |
| 手机活动与核对视图的标签页只有点击状态 | 补齐标签页与内容区域关联，支持左右方向键、Home、End，焦点与选中状态同步。 |
| 方法名称框允许 500 字，确认只接受 80 字；其他正文框比规则更短 | 名称 80 字，目标等正文 800 字，情况与做法 500 字；结束条件计入前缀限制。原则达到上限时停止新增。 |
| 编辑正文后点击补充或折叠按钮可能没有反应 | 避免输入框失焦收起改变鼠标下的按钮位置，让一次点击完成操作；键盘编辑继续按正常焦点顺序工作。 |
| 探究表单常驻字数、保存说明重复，手机文案仍要求看“右侧” | 字数仅在接近上限时显示；删除重复发布能力说明，底部不可发布提示仍保留；确认问题与学生预览文案不再依赖左右位置。 |
| 学生对话变长后看不到最新回应，点击发送或示例后需要重新点输入框 | 新回应滚动到对话底部，发送与选择示例后可直接继续输入；对话区域提供增量播报语义。 |
| 创建页从想法进入梳理、预览时保留旧位置 | 阶段切换回到顶部，并聚焦创建页标题。 |

## 检查结果

- `npm run build`：类型检查及生产构建通过。原有 Zod 注释和主包体积提示仍存在，未出现新增构建错误。
- 30 个不同浏览器场景分批通过，其中新增 7 个针对本次问题的回归场景。最后修改的创建与活动页面重新检查。

- 检查覆盖首页入口、集市筛选、作品返回、创建与核对、活动两条路径、学生对话及兼容页面。页面运行错误检查通过。

- 方法来源、学生预览中的方法详情折叠展示；报告保留当前方法和实际待验证事项。
- 不可发布、未真实执行、本机保存等边界仍明确显示；无新增真实运行能力或虚构证据。

类型检查和生产构建通过，44 个不同浏览器场景分批通过。首轮 3 项失败均因旧文案断言，更新对应断言后复查通过。沿用原有检查覆盖四种屏宽及主要页面；截图已更新。
