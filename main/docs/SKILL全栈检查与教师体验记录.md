# SKILL 全栈检查与教师体验记录

日期：2026-10-10。本轮在原绿色、白色前端上修改，基于上一轮线上版本 `f0d24ff`。2026-10-10 用户明确“把新版上传并发布”，本轮全部已展示改动已获提交与 Actions 发布授权；实际部署结果以对应提交的 Actions 记录为准。

## 本轮流程

创建：填写想法 → 问答或直接编辑方法 → 形成 SKILL → 检测演示回复并由教师确认 → 学生视角试用 → 发布到本机演示集市。

集市：查看与试用 → 学生输入／模型演示回复；添加到我的 SKILL → 保存来源版本，只读查看、试用或移除。试用不自动添加，添加不生成可编辑副本。全部 SKILL 改编入口、弹窗、需求字段和创建逻辑已删除；已有资料保留。

检测、集市试用和作者预览共用演示回复逻辑。它按所选情况与轮次展示有限样例，无法判断任意学生输入、任意方法或真实教学效果。无对应样例时明确提示。教师确认的是演示内容是否符合做法，不能作为真实模型执行证据。

## 已修复问题

| 问题 | 修复与核验 |
| --- | --- |
| 集市试用复述“教师会怎样做”，没有模型回复 | 原详情页呈现学生输入与面向学生的回复，保留方法说明供对照；按用户最新要求取消页面上的演示标识。 |
| 检测与试用内容不一致 | 检测分别显示输入、回复、预期做法和原则，使用同一演示逻辑；移除旧的“教师会……”回复函数。 |
| 用不同学科内容时容易套入数学示例 | 语文证据追问和朗读方法分别走查；不编造方程、答案或同类练习。否定做法中的引语不会直接冒充回复。 |
| 外部方法仍能进入改编流程 | 删除弹窗、调用参数、元数据字段及相关入口；收藏、只读添加与来源快照保留。 |
| 新用户“我创建的”混入六项预置方法 | 新工作区为空。兼容检查显式装入样例，已有本机资料保持原样。 |
| 已手动填完整的方法仍被六问阻挡 | 内容完整即可形成 SKILL，补充未保存时仍提示先处理。资深教师实际走完无需六问的流程。 |
| 检测中修改后旧草稿可能覆盖新做法 | 草稿关联来源版本；缓存同步失败保留旧输入，恢复时使用当前已保存的方法。 |
| 保存重试没有重试完整教学背景 | 重试同时保存目标、学段、学科等字段；失败保留输入。 |
| 失效编辑／步骤链接冒用其他方法 | 检查完整 SKILL 和步骤编号，显示恢复入口，不进入其他内容。 |
| 可选缓存删除或筛选保存失败可能中断页面 | 缓存清理不撤销已完成的保存；列表偏好失败仍可浏览。采用状态写入失败会恢复原选择。 |
| 损坏的个人资料启动时被重写 | 启动不自动重写资料；后续保存先保留原始记录。隔离检查验证恢复副本包含原文。 |
| 空或不完整的方法可能沿用旧核对状态 | 核对状态必须同时具有有效方法；没有情况的条目不显示已确认。 |
| 改单项方法覆盖多方法资料名称 | 保留多方法资料原名称；新建单项使用教师命名，作者预览显示当前 SKILL。 |
| 手机试用区藏在长步骤之后、对话无限增长 | 手机和平板先显示试用区；对话限高滚动、长英文换行、自动定位最新回复；低屏高取消固定面板。 |
| 原创建逻辑仍有未调用的关键词生成函数 | 删除旧 `design`、`messagesFor`、未调用的发布函数与相关状态持久化；旧对话资料保留。 |
| 后台无效 JSON、过长请求或空评审被当作服务器失败 | 分别返回 400／413，使用可读提示；不泄露解析错误详情。 |
| 上传解析异常、项目日期和邮箱输入处理不完整 | 解析异常转为可读提示；日期格式校验；邮箱去首尾空格并规范大小写；核验上传类型、文字与 5MB 限制。 |

缩短了六问中的说明与回复标签，统一使用“学生输入”“模型回复”“教师已确认”。保留明确的本机与演示范围说明，避免把演示包装成真实执行或对外发布。

## 三种教师身份走查

以下是基于三种身份设定的任务走查，由开发者在隔离浏览器中执行，并非真实教师访谈或用户研究。

| 身份与任务 | 完成情况 | 仍不够合适的地方 |
| --- | --- | --- |
| 资深教师：把语文证据追问经验直接写成方法，检测、试用、发布，再修改 | 已完成。无需重复六问；模型回复面向学生；修改撤销旧确认与集市展示。 | 旧数据以“助手”容器存多项方法，编辑一项仍影响整组核对与发布状态。单项 SKILL 的版本范围需要后续专门整理。内部“加入助手配置”也容易与外部模型挂载混淆。 |
| 职前教师：以朗读试讲计划完成六问，检查是否带入数学方法 | 已完成。自己的回答形成方法，演示显示停顿引导，不生成数学答案或教学效果。 | “通常会怎么做”的问法偏向已有教学经验；预设数学想法及示例回答仍可能让新手以为这是自己的方法。下一批应讨论空白起始与主动选示例。 |
| 教师初学者：找一个方法，试用后添加，再查看来源分类 | 已完成。个人工作区初始为空；试用不创建个人资料；添加项只读且来源固定；手机首先看到试用。 | 缺少面向初学者的 SKILL／挂载说明，也没有 SKILL.md 导出或外部平台导入步骤。添加仅完成收录，尚不能完成外部模型使用。 |

这些体验问题已经记录。跨平台文件格式、单项版本、旧助手入口和示例起始方式属于下一批设计范围，需先确定具体改动，再在原组件上逐项实现。

## 尚存范围与限制

- Pages 是静态 Demo。发布和作品保存发生在当前浏览器，无法让另一设备看到新发布的个人 SKILL；没有真实模型检测或自由对话。此次按用户明确选择沿用 Demo。
- PBL／教学活动主入口已移除，但旧直达路由、兼容模块以及项目指导样例内容仍存在；项目类分类与标签已按用户补充要求移除。不能声称 PBL 代码已全部删除。后续需要专门移除这些界面与依赖，同时保留旧教师资料。
- 原设计组件及多份历史样式仍有待分批整理。本轮清理无调用的旧创建函数和改编功能，没有重建页面或另建数据体系。
- 构建主包约 635 kB，压缩后约 200 kB。旧模块仍随主包加载，构建存在体积提示。后续清理兼容模块或分包时应单独验收。
