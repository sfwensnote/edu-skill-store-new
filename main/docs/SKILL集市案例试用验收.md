# SKILL 集市案例试用验收

2026-10-10。基于已发布的 `4575ac9`，用户确认设计后完成第一批本地修改；用户已确认发布，本轮进入提交、推送与 Actions 部署。实际发布结果以对应提交的 Actions 记录为准。

## 本批改动

原详情页右侧以具体案例替换步骤选择和空白输入框。题目与首条学生回答在进入页面时显示，点击“查看模型回复”后选择学生接下来的回答。不同回答对应不同引导，不按对话轮数递进。切换案例和重新试用回到初始状态。

现有五项集市方法提供六个案例，覆盖移项、分数加法、渐进提示、理解确认、费用比较和证据追问。试用使用有限对话分支，没有调用真实模型。方法内容与原案例不一致或没有对应案例时显示“暂无试用案例”，不套用其他方法的回复。

卡片两个按钮、搜索、分类、作者方法说明、收藏、只读添加与来源版本保持原逻辑。原作者的编辑、检测和学生视角预览未改动。对话不写入个人资料，不生成助手或可编辑副本。

## 核验

- 29 项相关 Playwright 场景通过：集市目录、案例全部分支、案例切换、重试、刷新、键盘焦点、添加与移除、来源快照、存储失败、标签兼容及原作者核对预览流程。
- 7 项相关单元检查通过：2 项案例匹配检查、5 项原指令与回复检查。方法的约定、触发或步骤改变后不沿用旧案例；同名自定义方法也不会套用。
- TypeScript 和 GitHub Pages 子路径生产构建通过。
- 1440、768、390、320 像素宽度核验无横向溢出；手机试用区域仍排在完整方法前面。长对话随页面阅读，取消该面板的固定定位，避免底部操作被遮挡。
- 初轮发现案例选择框的可访问名称包含选项文字，导致精确定位失败。已补充明确名称，随后 29 项检查全部通过。
- 补充修复重新试用后的焦点：返回“查看模型回复”按钮，键盘可以立即再次开始。修改后 5 项案例检查和生产构建复查通过。

测试使用隔离资料；未清空教师的浏览器存储或数据库。仅执行相关回归，不将本轮结果称为全量全栈检查。

## 教师身份核实

本节是开发者按教师任务进行的走查，不是真实教师访谈。

| 身份 | 本批结果 | 仍需后续改进 |
| --- | --- | --- |
| 资深教师 | 可对照原方法，分别选择学生补充过程、仍不会或索要答案，查看不同引导。 | 目前无法输入自己的课堂材料或学生回答，案例不足以证明真实模型效果。 |
| 职前教师 | 题目、学生回答和模型引导同屏呈现，可从对话理解抽象方法；原创建核对流程回归通过。 | 自己创建或已修改的方法没有自动生成的适用案例，会显示“暂无试用案例”。 |
| 教师初学者 | 不用自己编题或猜输入角色即可开始；试用与添加独立，添加项仍只读。 | 添加仍只完成收录，SKILL 文件下载及外部平台挂载说明尚未实现。 |
