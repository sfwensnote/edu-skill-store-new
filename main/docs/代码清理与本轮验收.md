# 代码清理与本轮验收

日期：2026-10-11。基于原版界面修改，按现有授权提交到 main 并通过 GitHub Actions 发布。

## 已完成

- 删除前端和测试均无引用的 AssistantDraft、DesignerChat、SkillSection、MyAssistantsPage、Switch，以及旧设计器样式文件。
- 删除无调用的活动创建、应用和模拟构造逻辑。旧记录的类型及校验器缩为 shared/legacy-activity.ts，兼容测试使用独立夹具。
- 删除废弃助手列表分支、闲置导出和无引用 CSS 规则，保留仍有调用的组件和动态状态样式。
- 将工作区存储键集中到 shared/workspace-keys.ts；值、账号隔离方式和一次性 SKILL 清理标记不变。
- TypeScript 启用 noUnusedLocals／noUnusedParameters，新增 npm run check:source，并纳入 Pages Actions。依赖图包含类型引用、再导出、动态导入和样式导入，测试夹具也计入；反向验证确认无引用文件会导致失败。
- 学伴卡片直接提供删除按钮。取消、确认、存储失败、重试和刷新都保留原删除机制，仅删除所选学伴。
- 我的 SKILL 侧边及手机分类新增我的收藏，汇集自己与集市的方法。取消收藏不删除方法；收藏不自动添加，添加后挂载只读来源快照。
- 创建顶部更紧凑，删除阶段小字；教学目标框架下提供左侧提示自动补全的说明。最后一问补充结束条件，原手动修改和草稿仍可恢复。
- 检验、学生视角及集市派生案例共用教学情况输入。情况 2 使用已尝试第一步但仍有困难的输入；指定步骤的预览不再按回复次数跳到其他步骤。删除不相关的固定数学对话。
- 首页、集市、我的 SKILL、我的学伴顶部统一缩短；桌面插画上下各留 4 像素，手机标题和按钮保留可用布局。
- 修正 320 像素导航等宽按钮压缩长标题的问题，按钮按文字宽度分配空间，避免“集市”和“我的 SKILL”文字重叠。

源码依赖检查和 TypeScript／Pages 子路径构建通过。Actions 仍仅部署静态网站，实际发布状态以本提交的运行记录为准。
