# 前端重设计 · Skill 中心单页工作区

更新：2026-09-09。

本方案替代此前的六步创建流程。最新创建流程不处理教学材料，也不要求教师理解模型、提示词或配置项。

## 当前信息架构

1. `#/library`：助手库，支持学段、学科、活动筛选与搜索。
2. `#/library/:id`：公共助手详情与使用入口。
3. `#/my`：当前教师的助手列表；按状态进入设计、检测或运行记录。
4. `#/create/:id`：左侧教学设计器、右侧实时助手设计稿。
5. `#/assistant/:id/test`：自动情境检测与技能结果。
6. `#/assistant/:id/use`：极简学生使用页。
7. `#/assistant/:id/logs`：最近 7 天运行记录。
8. `#/assistant/:id/logs/:sessionId`：日志详情。
9. `#/assistant/:id/report`：网页运行报告。

## 当前前端模块

- `src/components/AppHeader.tsx`：统一顶部导航。
- `src/features/library/`：助手库、个人助手、详情和紧凑列表。
- `src/features/designer/`：设计器对话、设计稿和 Skill 展开。
- `src/features/testing/`：检测情境、检查记录和 Skill 结果。
- `src/features/usage/`：使用页、运行记录、日志详情和报告。
- `src/hooks/useDemoPlatform.ts`：前端演示状态；后续由同名职责的 API 数据层替换。
- `src/styles/*-new.css`：按页面职责拆分的统一视觉系统。

## 已完成的前端路径

助手库搜索/筛选 → 创建助手 → 输入教学想法 → 逐项形成 Skill → 选择是否加入助手 → 展开查看 → 让设计器调整 → 生成助手 → 逐项确认七个检测情境 → 确认投入使用 → 查看运行记录 → 查看日志详情/报告。

当前前端使用本地演示数据与 `localStorage` 保持状态，目的是先完成视觉和交互验收。后端关系表、Mock AI 与 Qwen 接口将在下一阶段接入；页面不需要再次改变信息架构。
