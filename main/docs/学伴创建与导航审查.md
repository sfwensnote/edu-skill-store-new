# 学伴创建与导航审查

日期：2026-10-11。沿用原界面，修改学伴创建、挂载跳转和集市试用，用户随后明确授权清除旧任务内容；只清理旧任务与旧要素，SKILL 及新场景继续保存。不接真实模型或云存储。

## 本批功能

- 我的学伴：基本信息、选择 SKILL、教学场景、预览与保存四步。侧栏与右侧预览跟随当前输入，表单沿用原配色和组件。
- 教学场景：学习对象、学习情境两个选择框；学习任务与目标一个多行框。活动设计与材料选填、折叠显示。
- 基本信息支持名称、简介、学段、学科、选填年级及形象。上传头像实际读取与校验，不填充虚构聊天。
- 按用户最新授权清除旧教学任务、活动草稿、学伴九项旧要素和旧活动设计，不将旧内容复制进新表单。保留学伴名称、SKILL 引用和附件，旧学伴回到草稿。新版三项场景保留。清理按账号处理、失败回滚并提供重试；未知或损坏结构不覆盖。草稿支持逐步保存、返回和刷新；保存失败留住输入并提供离开保护。
- 我的 SKILL 没有试用按钮、步骤预览或试用侧栏。挂载只引用方法，不复制方法或改变归属。
- 发布到集市后从当前方法情况与做法派生试用案例，沿用有限回复规则。修改后的方法不使用旧绑定案例；不调用真实 LLM，不将有限回复称作真实执行。方法仍需教师检验确认后发布。

## 跳转问题

| 问题 | 原因与修改 |
| --- | --- |
| 查看已挂载学伴后仍留在“错因反思”，顶栏跳转失效 | 同级 SKILL 详情与挂载弹窗使用相同 React key；出现重复标识警告，旧 main 留在页面。页面与弹窗使用组件类型前缀，回归检查每次只有一个 main，且无控制台错误。 |
| 发布弹窗存在相同冲突 | 发布、编辑、检测、预览及旧任务页也统一使用类型前缀，防止跨组件标识相撞。 |
| 查看草稿学伴误入创建页 | 挂载弹窗的“查看学伴”直接打开选择的详情；学伴列表的“继续创建”仍进入编辑。 |
| 弹窗开启时浏览器返回，弹窗留在新页面 | 路由变化清理挂载和发布弹窗；返回、前进和刷新后菜单继续可点。 |
| 失效 SKILL 总是返回我的 SKILL | 保留原兜底设计，改为沿来源返回集市或我的 SKILL，不重复渲染兜底页。 |
| 学伴自动保存失败后切换页面可能丢失输入 | 复用公共保存失败离开保护，同时捕获 hashchange 与 popstate，防止浏览器返回时页面先卸载。可继续编辑、保存重试或明确离开。 |
