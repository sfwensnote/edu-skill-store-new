# Educational Skill Builder 实施计划

目标：按已确认方案交付文档与可操作本机 Demo。按用户要求直接在当前任务执行。

架构：React/TypeScript 工作台 + Express API；共享领域类型，SQLite 项目保存。真实接口与演示模式分别标识。

- [x] 文档与骨架：`docs/项目设计.md`、`PRODUCT.md`、`DESIGN.md`、Vite、共享 schema。
- [x] 业务核心：`shared/domain.ts` 维护配置与状态失效；`server/models.ts` 负责模型调用；`server/materials.ts` 提取文字；测试覆盖上下文、边界和版本。
- [x] 持久化：`server/store.ts` 和 `server/auth.ts` 管理本地账户、会话和项目隔离。
- [x] 工作台：`src/App.tsx` 和 `src/pages/*` 完成六步、项目列表与模式显示；`src/styles/*` 响应式布局。
- [x] 证据闭环：`server/evaluation.ts`、报告生成；演示不填虚构分数。
- [x] 验收：`npm run build`、`npm test`、Playwright 完整流程与桌面/390px 截图；启动本机预览并打开 Codex 窗口。
- [x] 前端重设计：frontend-design 视觉方案 + shadcn 基础组件，浅色中性工作台，手机导航与账户焦点检查。

接口合同：`/api/status` 返回模式；`/api/design` 返回 Brief 与 Skill；`/api/materials` 返回提取文字；`/api/chat` 返回当前模式回复；`/api/evaluate` 返回逐项证据；`/api/auth/*` 与 `/api/projects` 保存当前账户数据。

尚待外部条件：用户提供通用设计模型与已有微调模型接口后，进行实际连接、上下文容量和教学表现验收。当前协议测试使用本机测试服务，不视为真实模型验收。
