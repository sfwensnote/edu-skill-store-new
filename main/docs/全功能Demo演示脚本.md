# 教学工坊全功能演示脚本

适用于本机客户演示和内部走查。建议完整演示约 20 分钟；只讲核心价值时可按文末的 8 分钟路线演示。页面数据保存在当前浏览器本机，不会同步到其他设备。

## 演示前准备

打开 `http://127.0.0.1:5173/#/home`。演示过程会新建本机草稿和作品；如果浏览器里已有教师自己的内容，不要为了演示清理数据。可在名称中加上“演示”，例如“演示·租赁方案比较”，演示结束后由教师自行决定是否删除。

建议贯穿使用同一个七年级数学案例：学生比较两种设备租赁费用，先弄清固定费用和每小时费用，再根据使用时长作出有依据的选择。它能串联教学方法、情境题、任务链、PBL、教学任务和 SKILL 应用。

> 界面中出现的“固定示例”“规则模拟”“教师预设提示”都不是实时模型生成结果。当前可以演示教师整理方法、编辑确认、作品保存、学生视角预览和本机记录；真实教学助手执行、学生账号访问、云端发布与正式启用尚未接入。

## 一、首页与创建入口

从首页依次介绍两条主要路径：

- 「日常教学」：把教师自己的课堂做法整理为可复用的教学 SKILL。
- 「情境探究」：围绕原题或知识点，分别设计情境题目、任务链或 PBL 项目。

再展示下方「教学 SKILL 集市」「我的作品」「教学任务」三个入口。点击顶部「创建」，分别选择「整理日常教学方法」或「设计探究作品」，确认它们会进入对应流程。

## 二、日常教学：教师经验整理为 SKILL

从首页「日常教学」进入，填写自己的想法；需要参考时可以主动填入示例。可直接使用这段：

> 七年级学生比较两个租赁方案时，经常只看每小时价格。我想先让他们自己找出固定费用和计时费用，再比较同一时长下的总价，不要直接告诉他们选哪家。

学段选「初中」，学科选「数学」，教学分类选「智能练习」，额外标签可填「租赁费用比较」「一次函数」。分类必选，和集市一致；标签用于补充知识点。预填的示例想法首次点击会清空，教师自己填写的内容不会因此丢失。进入梳理后，逐题输入以下回答。示例答案按钮也可用来体验，但现场逐题输入更能展示教师如何表达判断。

| 提问 | 可直接填写的回答 |
| --- | --- |
| 你希望通过这种做法，学生最终能够发生什么变化？ | 学生能先回顾自己的比较依据，分清固定费用和计时费用，再用总费用解释选择。 |
| 你通常在看到学生什么表现时，会开始这样做？ | 学生第一次只看每小时价格，或者说不清总费用怎么来的时候，我开始追问。 |
| 这种情况下，你通常会先怎么做？ | 我先让学生把两个方案中的固定费用和每小时费用分别圈出来，并说明每一项代表什么。 |
| 完成这一步后，什么表现会让你改变接下来的做法？ | 如果学生仍然只比较单价，没有把使用时长带进计算，我会继续介入。 |
| 这种情况下，你接下来怎么做？ | 我请学生任选一个具体时长，分别计算总费用再比较；我不替他做最终选择。 |
| 有什么事情是你明确不希望助手做的？ | 学生还没有解释依据前，不直接公布哪种方案更省；不把虚构报价说成现实市场价格。 |

逐题提交后，右侧方法提纲会随回答更新。可以直接修改提纲中的问题、目标、开始条件、每种情况的做法和教学原则；也可以补充新的“学生表现—教师做法”。点击「形成 SKILL」后直接进入方法核对，不再经过独立预览确认页。可选的「预览 SKILL」仍作为页内弹窗保留。

形成后进入方法核对：按页面逐项确认由这套方法整理出的核对情境，完成后可回到我的作品查看，或打开学生视角预览。发现不准确的做法时，在核对页点击「修改当前方法」，保存后从第一项重新核对。学生预览可切到「方法步骤」，点第二步的「预览这一步」，体验学生仍未发现问题时的继续介入。预览结束直接点「完成，返回我的作品」，或「分享到集市」；核对记录在同页折叠查看，不必再绕到摘要页。介绍时说明：核对的是方法内容，固定示例不会调用模型，也不能证明执行效果。

**预期结果：** 一项包含教学目标、触发条件、教学步骤和原则的独立 SKILL；改动后需要重新确认，未确认前不会作为已核对方法应用。

## 三、情境探究：从一道题形成三种独立作品

从首页进入「情境探究」，选择一种成果。三个成果互相独立，不要求按顺序全做。

### 3.1 情境题目

点「填入数学租赁示例」，教学背景会带入：

- 教学内容：已知两个收费方案 `y_A = 8x + 10`、`y_B = 5x + 25`，比较不同 `x` 值时的费用。
- 学科：数学；知识点：一次函数及函数模型的比较。
- 学生目标：根据函数模型比较费用，并说明不同活动时长下的选择依据。

开始设计后，在题目中检查情境、问题、知识目标、保留的数量关系和教师核对事项。示例答案应为：两式相等时 `x = 5`，费用都是 50 元；`0 < x < 5` 时 A 较低，`x > 5` 时 B 较低。举例：2 小时 A 为 26 元、B 为 35 元；8 小时 A 为 74 元、B 为 65 元。确认虚构数据仍按教学数据呈现，勾选教师确认并保存。

可以切换到「学生内容预览」，再用「导出方案」「复制文本」「打印」或「创建副本」展示后续使用方式。「保存并布置任务」会进入教学任务工作台。

### 3.2 任务链

回到情境探究，仍填入数学租赁示例，改选「任务链」。建立任务框架后，逐项查看或调整任务的要求、对应能力、学生产出和教师支持。示例会形成四步：

1. 理解计费规则：区分固定费用和每小时费用，说明 `x`、`y` 的单位和范围。
2. 建立并比较模型：写出两个函数，比较 2、5、8 小时的费用。
3. 找出临界条件：求费用相同的时长，解释临界点前后的选择。
4. 提出选择并论证：按实际时长给出建议；时长未知时说明还需什么信息。

逐项核对任务递进关系和产出，再保存任务链。此案例中临界时长为 5 小时。

### 3.3 PBL 项目

回到情境探究，选「PBL 项目」，先判断五项实施条件：

| 条件 | 本案例演示判断 |
| --- | --- |
| 存在值得持续探究的实际问题 | 是：学校需要按活动需求选择设备租赁方案。 |
| 需要多阶段调查或实践 | 是：经历需求整理、信息收集、建模比较和方案展示。 |
| 学生有自主决策空间 | 是：学生根据活动时长、预算和需求提出建议。 |
| 有明确的项目成果 | 是：形成包含模型、预算比较和推荐依据的方案。 |
| 时间、资源和安全条件允许实施 | 是：课堂中使用虚构报价开展模拟分析；真实调查须由教师另行确认。 |

条件确认后整理项目草案，并检查项目名称、驱动问题、目标、活动、阶段、资源、成果、展示、评价和实施安排。可用驱动问题：“在活动需求、时长和预算限制下，我们怎样为学校提出有依据的设备租赁建议？” 核对项目方案后保存。

如果案例并不需要持续探究，演示时应选择情境题或任务链，而不是为了展示功能把它包装成 PBL。也可点「填入校园观察示例」，体验生物学案例：比较校园两处花坛的光照、水分和植物生长，连续观察一周，并明确“不采摘植物”、区分观察事实与推测。

## 四、教学 SKILL 集市：发现、体验、收藏与复用

进入「教学 SKILL 集市」，搜索「反思」或「费用」，再按学段、学科、板块、教学分类与标签筛选。打开「错误后反思引导」或「费用比较中的信息提取与论证」详情，依次查看用途、触发条件、步骤、教学原则和具体使用示例。

在「引导预览」里输入：

> 两个方案我只看每小时价格，A 每小时 8 元，B 每小时 5 元，所以我选 B。

点击查看示例，页面会展示一条依据该方法生成的固定引导示例。之后可以收藏，或选择「复用到我的作品」。复用后回到我的作品，可看到自己的独立副本；修改副本不会改动集市原条目。

集市中的教师、方法及示例是演示目录数据，不代表真实教师背书、真实使用记录或模型测试结果。集市 SKILL 需要先复用到自己的作品并完成适用条件要求，才可用于应用配置。

## 五、我的作品：管理、预览和复用

进入「我的作品」，按左侧分类查看「我的 SKILL」「情境题目」「任务链」「PBL 项目」「我的收藏」「作品展示」「我的助手」。用顶部唯一的搜索框和学段、学科、排序筛选，展示一项作品的查看、编辑、复制、收藏和更多操作。

建议演示这些低风险操作：

- 打开刚创建的情境题目，切换学生预览并返回编辑。
- 复制一份情境题或集市 SKILL，展示副本与来源分开。
- 在集市收藏一项方法，再到「我的收藏」查看；取消收藏后列表随之更新。
- 对自己的作品使用「分享展示」，再打开「作品展示」查看当前工作区内展示的内容。它不会上传到公共网络。
- 对集市 SKILL 使用「加入已有助手配置」时，选一个助手后说明系统只添加独立配置副本，仍需回到助手确认，不会自动启用。
- 打开「我的助手」中的旧版助手，恢复对应方法的编辑、核对或预览。

删除会连带移除相关内容，且部分操作不可撤销。演示用户自己的资料时，不要实际确认删除；可以只打开确认提示，说明影响范围后取消。

## 六、教学任务与方法应用

### 6.1 新建教学任务

进入顶部「教学任务」，点「新建教学任务」。这里只选择情境题、任务链或 PBL 项目，不把 SKILL 当作学生题目。

前提：我的作品中有已保存并确认的作品。搜索“租赁”或“一次函数”，选择“选择合适的设备租赁方案”。

第 2 步可填写：

- 任务名称：两种设备租赁方案比较
- 任务说明：请分别计算 2、5、8 小时的费用，找出费用相同的时长，并说明选择依据。请保留计算过程。
- 学习对象：指定班级；范围填写“七年级 1 班”。这只是配置记录，不会创建真实班级或开放访问。
- 提交方式：文字回答；允许多次尝试。
- 反馈时机：提交后显示教师提示；提示可写“请检查是否把固定费用和每小时费用都计入总价。”

第 3 步选择不使用 SKILL，展示支持可选。第 4 步预览并保存草稿，再打开学生预览填写：

> 2 小时选 A；5 小时两家都是 50 元；8 小时选 B。费用相同时，8x + 10 = 5x + 25，所以 x = 5。选择取决于使用时长。

提交显示教师预设提示，并在本机教学任务中留下预览记录。保存后返回任务列表，再打开草稿检查可恢复。空白新建页直接返回，不弹出多余确认；实际修改后离开会保护输入。

### 6.2 应用教学 SKILL

从「我的作品」的方法卡片点「应用 SKILL」，或在方法详情的更多菜单中进入。这里配置方法的使用方式，不创建新任务。

选择自己拥有、已完成教师核对且具有教学原则的数学方法，再选择上一节保存的教学任务。介入范围可写：

> 仅当学生只比较每小时费用，且无法解释总费用时，按已确认方法提示；不直接替学生选择方案。

第 3 步测试情境可写：

> 学生说：“B 每小时更便宜，所以不管活动多久我都选 B。”他还没有计算总费用。

触发判断选「符合原方法触发条件」，点「查看模拟步骤」，检查方法计划和约束，再进入最后一步「保存配置」。

这只是依照教师判断展示计划，不是自动运行。配置保存在「我的作品」的「SKILL 应用配置」折叠区，可继续编辑。教学任务列表不会多出一项方法预览。

## 七、方法预览与历史数据

方法预览的「体验引导」和「方法步骤」是两种查看方式。步骤明确配对显示学生表现与教师做法，每一步都有直接预览入口。切换方法或步骤后使用相应固定引导，不冒用另一套方法。

核对完成后可在同一页查看折叠的核对记录、返回作品或分享当前方法；多方法配置只分享当前选中的方法。未核对或未采用的方法不能被标成已验证方法分享。

旧版助手、报告与步骤地址继续兼容，但不再作为新方法的必经路线。历史方法试用只在我的作品中保留，不混入教学任务。原资料和提交记录不会因流程简化而清空。

## 演示时的准确说法

- “创建 SKILL”表示把教师确认过的条件、步骤和原则整理为结构化方法，不表示模型已经学会或真实执行。
- “教师核对完成”表示教师在演示流程中确认了方法内容，不表示算法评测通过或教学效果有效。
- “学生预览／学生端”是本机视角演示，不是真实学生账号或线上课堂。
- 真实发布与“启用 SKILL”尚未接入；可以保存本机草稿、预览和体验规则模拟。
- 作品展示、收藏、任务提交和配置都保存在当前浏览器，不会自动上传、分享给其他人或同步设备。
