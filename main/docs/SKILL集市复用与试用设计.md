# SKILL 集市复用与试用设计

2026-10-10，用户已确认设计方向及第一批发布。详情页试用已在原组件上实现并完成本地核验，进入提交与 Actions 发布。用户同时授权以后每批检查通过后直接发布，方便在线验收。第二批下载与挂载流程仍未实现。

## 需要解决的问题

教师浏览别人的 SKILL，要判断它是否适合自己的学生、采用后模型如何回应，以及怎样拿去使用。

当前详情页没有把这三件事连起来：

- “预览教学情况”的选项实际是方法步骤，没有题目、学生表现或具体对话。
- 空白输入框要求教师自己编学生的问题，也没有说明教师是在观察还是扮演学生。
- 回复根据对话轮数推进，未根据学生回答选择做法。学生没有继续尝试，模型也会进入下一步。
- 添加只是保存作者版本的只读快照。集市添加项没有获取文件或外部挂载入口，流程停在收录。

已核对 `MarketPages.tsx`、`SkillChatPreview.tsx`、`MethodSituationSelect.tsx`、`shared/method-preview.ts`、`shared/skill-preview.ts` 与我的 SKILL 操作。

## 使用流程

```text
集市：查看与试用
  ↓
详情：判断适用情况 → 看一个具体案例 → 选择学生回答，观察模型回复
  ↓
添加到我的 SKILL
  ↓
我的 SKILL：从集市添加 → 下载 SKILL → 在外部平台自行挂载
```

| 操作 | 教师获得什么 |
| --- | --- |
| 查看说明 | 知道什么时候适用、如何引导、有哪些限制。 |
| 试用 | 看到采用这项 SKILL 后，模型如何回应具体的学生回答。 |
| 添加到我的 SKILL | 留存作者的这一版本，后续可以继续查看、试用和获取文件。 |
| 下载 SKILL | 获得用于外部挂载的文件；不会自动启用模型或连接外部账号。 |

集市卡片保留原来的两个按钮、搜索、筛选和视觉。收藏仍只用于标记，添加用于收录到个人列表。

## 详情页调整

沿用原页头和左右两栏。左栏保留原方法内容，右栏调整试用。手机先显示简短说明与案例，完整方法可展开阅读。

```text
错误后反思引导                         [添加到我的 SKILL] [收藏]
学生答错后先了解他的思路，再给予针对性帮助。
作者、学段、学科、版本

┌ 方法说明 ──────────────────┐  ┌ 试用 SKILL ─────────────────────┐
│ 适用：学生答错或解题出现偏差 │  │ 选择学生的回答，看模型如何引导。 │
│ 目标：让学生自己找出问题     │  │                                  │
│                            │  │ 案例：移项时弄错了符号            │
│ [展开完整方法]             │  │ 题目：解方程 2x + 3 = 9           │
│ 步骤、约定、课堂使用        │  │                                  │
│                            │  │ 学生：我算出 x=6，但答案说不对。  │
│                            │  │ [查看模型回复]                    │
│                            │  │                                  │
│                            │  │ 模型回复：你是怎样得到 x=6 的？   │
│                            │  │ 把你的计算过程写出来。            │
│                            │  │                                  │
│                            │  │ 选择学生接下来怎样回答：          │
│                            │  │ [我写成了 2x=9+3]                 │
│                            │  │ [我不知道下一步怎么做]            │
│                            │  │ [我想直接看答案]                  │
│                            │  │                                  │
│                            │  │ [重新试用]                        │
└────────────────────────────┘  └──────────────────────────────────┘
```

“案例”只提供试用所需的题目与学生回答，不恢复首页或创建中的情景功能，不建立教学活动、任务或 PBL 模块。案例选项使用具体问题名称，不使用“步骤 1 / 步骤 2”。

进入详情就能看到题目和首条学生回答，不先显示空白聊天。点击“查看模型回复”后显示模型的直接回答，再让教师选择学生接下来的回答。不同选择应触发相应的引导，不能仅按点击次数递进。

例如，学生补充“我写成了 2x=9+3”，模型再追问：“为了消去左边的 +3，等式两边应该做什么？先写出这一步。”学生索要答案时，则保留独立尝试的机会。以上对话是拟定案例，需核对是否符合该 SKILL 的做法与约定后才能采用。

本轮沿用有限案例，先用可选学生回答完成有依据的试用，不保留能随意换题却得到通用回复的输入框。不增加 Demo、演示或预置标识，不宣称这些案例已经由真实模型执行或证明教学有效。自由输入留到能够根据输入回应时接入，异常情况不能编造有效结果。

## 添加以后

添加成功提示：`已添加到我的 SKILL`，提供 `去我的 SKILL` 链接；详情页按钮变为 `已添加`，不重复保存。

“从集市添加”保留作者、来源和固定版本。卡片主操作为 `查看与试用`、`下载 SKILL`；移除放进原有菜单。没有编辑、改编、重新检测或以自己名义发布入口。

下载使用添加时保存的版本，包含方法内容与来源信息。先提供 `SKILL.md` 文件及简短挂载说明；具体字段、目录和附件规范在实现前核对，不承诺兼容所有平台。外部平台的导入方式尚未确定，因此本轮不增加平台选择、授权连接或一键挂载。

下载与收录是不同动作：下载不会改变方法、创建助手、启用 SKILL，也不会自动发布。现有只读快照和历史个人资料继续保留。

## 分批验收

第一批只改集市详情的试用：

- 保留原集市卡片、导航、配色、添加逻辑和作者编辑流程。
- 用具体案例替换步骤选择器，首屏有题目、学生回答和明确的查看回复按钮。
- 显示对学生的直接回复，方法说明与回复分开。
- 根据学生的不同选择呈现对应回复，不按轮数强行进入下一步。
- 至少检查：学生补充过程、仍不会、索要答案、重新开始、切换案例、无适用案例。
- 缺少适用案例时显示 `暂无试用案例`，仍可查看方法和添加，不拼接虚构回复。
- 桌面和手机均可完整阅读、选择及重试，键盘操作可用。

第二批补齐添加后的使用：

- 明确添加成功及个人列表的位置。
- 增加只读 SKILL 文件下载与挂载说明。
- 下载内容来自已添加快照，来源更新或撤下不影响已保存版本。
- 检查重复添加、下载、移除、保存失败，不改变原作者资料或历史教师资料。

按用户最新授权，每批完成必要检查后直接提交、上传并通过 GitHub Actions 发布，再提供网址和结果供用户在线核实。

## 三类教师的核实重点

以下为核实标准；本轮隔离浏览器的完成情况与尚存限制见 [第一批验收记录](SKILL集市案例试用验收.md)。

| 身份 | 核实问题 |
| --- | --- |
| 资深教师 | 能否快速判断适用范围，并通过学生不同表现检验引导是否合适？ |
| 职前教师 | 能否从具体对话理解方法，而不是仅阅读抽象步骤？ |
| 初学教师 | 是否无需编题、猜角色，就能完成第一次试用，并找到添加后的 SKILL？ |
