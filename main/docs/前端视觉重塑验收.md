# 前端视觉重塑与验收

2026-10-12。依据用户提供的《教学工坊 24 小时 React Codex 前端重构 Prompt 修订版》，在现有 React 前端中按切片统一展示层，保留业务、资料和路由兼容。24 小时是项目交付预算，不是单次会话运行时长。

## 统一设计与范围

- 复用当前 CSS Tokens、Radix/shadcn 组件和公共导航，使用深绿、白色、浅灰绿。正文以 15px、约 1.6 行高为基准，主标题 28–30px，字重以 400/500/600 为主；辅助文字不替代正文。
- 页面使用清晰的横向资源行、紧凑筛选与主要操作，卡片无厚重投影。资源页通常采用约 1440px 内容宽度；教学编辑与聊天工作台保留宽屏空间，手机改为单栏。
- 保留首页、教学 SKILL 集市、我的 SKILL、我的学伴四项当前导航。已取消的教学活动、情境探究与 PBL 一级入口不因参考文档旧产品示例恢复。
- 继续使用前端 preview 模式；真实 server 模式不降低验证要求。规则预览、教师核对与真实执行保持区分，不接入真实模型或学生链接。
- 不迁移框架、Hooks、状态库、存储键、版本引用或后端接口；不覆盖教师已确认的方法，不清空资料，不添加虚构统计。
- 创建学伴单页化是高风险流程变化。当前先保留四步流程及原字段校验、草稿保存、文件读取、失败保护与离开提醒；没有等价验收证据不强行替换。

## 切片顺序

1. 先封版已有学伴案例与独立聊天：核对案例资格、错误表达、创建保存、刷新、历史、结束、存储失败、手机布局及独立只读 review。
2. 统一 Tokens、公共布局与导航，并应用到首页。仅调整主题、排版、间距与展示，保留所有回调与入口。
3. 统一集市、我的 SKILL 与学伴资源展示。保留搜索、筛选、详情、收藏、复制与确认操作的实际行为。
4. 对学伴创建、详情、聊天及教学方法/检测工作台应用统一展示规范；复杂流程不以静态界面代替。

每个切片先备份重要文件。用户明确将 Worker 并发上限设置为 8，按最多八个 Worker 的独立写入范围并行，实际数量不超过当前会话运行时容量；共享界面发生变化时不同时跑浏览器验收。实现完成后集成、针对性检查、独立只读 review，再按用户授权提交 main、推送指定仓库并核对 GitHub Pages Actions 结果。
