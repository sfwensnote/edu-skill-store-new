# 我的学伴与发布入口验收

日期：2026-10-10。范围以本轮用户要求为准，沿用原前端和既有发布授权。

## 本轮改动

- 我的 SKILL 卡片、个人详情直接提供“发布到集市”；未检验先说明原因，检验完成后可发布，已发布可查看和撤下。集市添加项不取得发布或编辑权限。
- “方法检验”直接准备已有方法并进入检验，不把 DRAFT 或未采用的方法绕回编辑。保存失败保留原页面和资料。
- “挂载到学伴”选择已有学伴或预选该 SKILL 创建新学伴，仅保存关联 ID，重复挂载去重，不写入个人 SKILL。
- 新导航“我的学伴”：选择个人方法（包括只读集市添加项）、命名 → 教学任务要素表、材料、可选情景题／PBL → 教学活动。普通活动不必启用这两个选项，已填写的选配内容取消后不进入活动。
- 任务要素包含名称、学习对象、学科、课时安排、学习目标、学情、任务、成果、评价要求。草稿按账号保存；支持刷新恢复、返回修改和附件下载。
- 删除旧教学任务应用编辑器、六个相关页面组件、三个独占样式文件，以及原复制式挂载和无调用的旧保存函数。保留历史资料解析和旧任务档案，不迁移或删除教师资料。

## 验证边界

仍为前端演示，无真实模型、后端登录或云存储。任务说明由教师填写内容整理而成，情景题与 PBL 由教师编辑；不声称任意内容已由 LLM 理解或生成。TXT／Markdown 读取实际正文，PDF／DOCX／图片保存原附件，可下载，不伪造解析结果。每文件最多 2 MB，总附件最多 3 MB；浏览器容量不足时保留当前输入并允许减小附件重试。

不声称全部历史 E2E 均通过。已移除的旧教学任务 UI 用例不再代表当前验收合同；当前重点为发布、方法检验、挂载关联、任务保存、选配设计、手机布局和原账号流程。实际结果以本轮测试日志和对应 GitHub Actions 为准。

92 项单元与集成测试通过；28 项相关浏览器场景通过，覆盖普通活动、情景题、PBL、选配取消、上传与下载、草稿刷新、挂载去重、集市只读来源挂载、发布失败重试、方法检验、账号隔离与管理员、320／390 像素布局。Pages 子路径构建通过。初轮旧按钮断言失败，按当前文案及流程更新后复查通过；未降低功能断言。检查截图和日志保存在会话验收目录，不提交测试生成的旧文档截图。
