# 教学工坊产品说明

更新日期：2026 年 10 月 10 日。本文区分本轮 SKILL Demo 与保留的旧版流程。原有助手社区、材料上传和六步后台流程不能作为当前前端已接入真实服务的证明。

## 当前 SKILL Demo

核心价值：将教师经验整理成可复用的教学 SKILL，供教师采用和 AI 执行。同一方法可以提供给外部平台，也可能由外部模型接入本产品；接入方向与协议暂未确定。

当前首页进入“我的 SKILL”，主导航为“我的 SKILL”和“SKILL 集市”。主流程为：记录经验 → 整理方法 → 教师核对 → LLM 检测 → 发布到集市 → 使用者下载并自行挂载。PBL、情境设计、教学任务和助手管理暂不进入此流程。

SKILL 独立保存身份、草稿、内容版本与核对记录。可借助预设问题整理，也可直接填写完整方法；形成版本不强制六问全部完成。条件与做法之外，还需写清使用前的信息、教学原则及不适用或教师介入的情况。

核对、检测和发布绑定当前内容版本；形成修改后的版本会清除该 SKILL 的旧核对、检测和本机发布状态，不影响其他方法。复用保留来源与来源版本，不继承核对、检测或发布。

Demo 默认检测模型已接入，LLM 仅出现在作者检测工作区。检测输入、模型回答和检测意见标为演示数据，覆盖所有教学分支及信息不足情境；需通过当前版本检测后才能发布。集市只展示说明、来源和版本，提供 SKILL.md 下载与自行挂载指引，不提供预览、聊天或在线运行。实际格式兼容与执行效果由使用者在目标平台验证。

本轮用户确认先完成流程 Demo，没有接真实模型接口。发布保存在当前浏览器，不向公网上传资料；不能将演示检测通过称为真实模型已验证。

新资料保存在 `teaching-skill.workspace.v1`；旧版浏览器资料不清空。原有页面可通过页脚“查看旧版作品”及旧路由访问，批量迁移尚未实现。保存失败时保留输入、阻止丢失草稿，不继续显示形成或核对成功；无法解析的旧存储不被默认资料覆盖。

设计及数据归属详见 [教学 SKILL 产品重设计与 Demo](docs/教学工坊产品重设计草案.md)。以下为保留的旧版能力与约束。

## 用户与目标

面向在职教师，将课堂中的判断、做法与原则整理为可复用的教学 SKILL；独立设计情境题目、任务链和 PBL 项目；将作品布置为教学任务，并预览学生的学习过程。

## 旧版功能合同（兼容保留）

| 空间 | 教师任务 |
| --- | --- |
| 日常教学 | 填写想法 → 六轮互动问题与方法编辑 → 形成 SKILL 并直接核对 → 学生视角预览 → 返回作品或分享。 |
| 情境探究 | 选择成果 → 教学背景 → 编辑与确认 → 分别保存情境题目、任务链或 PBL，不强制依次完成全部层级。 |
| 教学 SKILL 集市 | 搜索、筛选、收藏、查看方法与固定引导示例，复用独立副本。 |
| 我的作品 | 用一个搜索框查找作品，管理 SKILL、探究成果、收藏及本机展示；恢复草稿，编辑、复制或删除；折叠管理 SKILL 应用配置与历史方法试用。 |
| 教学任务 | 查看我的任务或新建教学任务，选择探究作品，保存草稿、查看学生预览与本机提交记录。 |

教学任务：选择已确认作品 → 任务要求 → 可选教学支持 → 预览保存。

SKILL 应用从我的作品进入：选择方法 → 选择已有任务与介入范围 → 查看模拟步骤 → 保存配置。它是方法的使用设置，不创建新的学生任务。

任务要求不修改源作品，方法应用不改写教学决策。已有学习记录的任务保留快照，后续调整另建副本。创建、核对或预览 SKILL 都不增加教学任务。

## 产品原则

- 先表达经验，再整理方法；不从一句想法编造教师的全部步骤。
- 教师最终修订优先于问答记录；未提交输入只存为草稿。
- 内容核对、规则模拟、真实执行与教学效果分别记录，不相互替代。
- 收藏、分享、配置和启用分别处理，本机展示不改变运行状态。
- 持久化成功才显示操作成功；失败保留内容并提供重试。
- 每一步突出当前问题或任务，次要操作收进菜单和折叠内容。
- 界面使用简体中文与大写 SKILL，统一使用“教学分类”，与集市六个分类对应；教师可以额外填写知识点等标签。
- 保留绿色、白色与浅灰绿色设计体系，减少宣传文案、重复边框、同一页面上的重复搜索和不能完成的操作。

## 实现边界

当前前端不调用真实 LLM、不新增后台服务，数据保存在同一浏览器的 localStorage。追问为预设六问，自定义探究内容提供教师编辑框架，不声称自动完成任意学科生成、答案校验或语义适配。

学生入口是教师的学生视角预览，提交只保存在本机。真实学生发布、学生账户、教学助手运行、SKILL 正式启用、执行轨迹、学习效果验证与跨设备同步尚未接入，相关正式入口不可操作。

原有 Express、SQLite、认证、模型与材料解析模块保留，当前页面主要流程没有调用这些服务。本地服务只监听 `127.0.0.1`；经用户授权，演示前端可通过 GitHub Actions 部署到 GitHub Pages。Pages 只托管静态构建，作品仍保存在访问者浏览器，不运行上述后台模块。
