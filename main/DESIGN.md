# 教学助手 · 视觉与交互规范

当前版本采用“资源库 + 单页设计器 + 检测工作区 + 运行管理”结构。视觉基准为项目 `images/` 下的四张参考图，重点是成熟教育软件的信息组织，而不是展示 AI 技术。

## 页面骨架

- 全局只保留 58px 顶部导航：教学助手、助手库、我的助手、创建助手、教师头像。
- 页面有效宽度为 1200–1480px，充分使用桌面空间；不使用全局侧栏。
- 助手库使用左侧纯文字筛选与右侧紧凑列表，不使用卡片网格。
- 创建页为 40% 教学设计器与 60% 助手设计稿；900px 以下切换为两个页签。
- 检测页为测试记录与技能结果双栏；完成后保留七个情境结果，不留下大面积空白。
- 运行记录页使用摘要条、日志列表和技能使用侧栏，Active 助手从“我的助手”直接进入这里。

## 视觉系统

| 角色 | 颜色 |
| --- | --- |
| 页面/内容背景 | `#FFFFFF` / `#FBFCFE` |
| 主文字 | `#0F172A` |
| 次级文字 | `#475569` |
| 弱文字 | `#94A3B8` |
| 分隔线 | `#E4E9F0` |
| 品牌蓝 | `#2563EB` |
| 浅蓝背景 | `#EFF6FF` |

字体使用系统无衬线栈：`-apple-system`、`BlinkMacSystemFont`、`Segoe UI`、`PingFang SC`、`Microsoft YaHei`。页面标题 25–30px，区块标题 16–19px，正文 14–15px，辅助信息 12–13px。

普通控件圆角 6–8px，主要区域 9–11px。层级主要依靠排版、间距和 1px 分隔线；阴影只用于工作区和主要操作的轻微抬升。图标统一使用 Lucide 线性图标，不使用 Emoji、彩色插画和无含义的小装饰。

## Skill 设计

Skill 是创建页的视觉主角。默认只显示名称和一句说明，一次只展开一项。展开后按“教学目的、什么时候使用、助手会怎么做、需要遵守”组织；右侧只读，通过“让设计器调整”把编辑上下文带回左侧自然语言输入。

不显示序号、固定类型、Prompt 字段或技术参数。创建阶段不出现教学材料。

## 交互约束

- 教师首次描述需求后，先形成名称、目标和一项最核心 Skill；后续对话再逐项新增或修改，不一次铺出完整 Skill 集合。
- 每项 Skill 都可以选择“已加入 / 不加入”；未加入的 Skill 不进入助手生成和检测，至少加入一项才能生成。
- 点击生成助手先展示生成状态，完成后才出现“开始检测”。
- 检测准备约七个情境，每项展示结果后由教师确认，再进入下一项；状态只使用通过、需要关注、未通过、检测中、等待检测。
- 确认投入使用后进入运行记录；日志、详情、使用页和报告都可返回原上下文。
- 390px 宽度下不产生横向滚动，创建和检测使用页签切换主次区域。
