# 教学工坊

让教师的教学经验成为可复用的智能教学能力。

当前首页为聚焦 SKILL 的 Demo：记录教师经验 → 整理方法 → 教师核对 → LLM 检测 → 发布到集市。检测页按模型已接入设计，输入、回答和检测意见使用明确标注的演示数据。集市只有说明与 SKILL.md 下载，不提供预览或在线运行，使用者需要自行挂载。形成新版本后重新核对、检测和发布；复用副本保留来源。

PBL、情境设计、教学任务和旧助手管理暂时退出主流程，代码与浏览器资料保留，可通过页脚的旧版作品入口查看。新资料不覆盖旧资料。设计与数据关系见 [产品重设计与 Demo](docs/教学工坊产品重设计草案.md)。下面的审查文档记录旧版功能。

最新流程、需求逐项核验和交互证据见 [流程简化与需求核验](docs/流程简化与需求核验.md)。任务与方法的关系见 [教学任务与 SKILL 应用](docs/教学活动创建说明.md)。此前的逻辑审查记录见 [项目逻辑审查](docs/项目逻辑审查与修正.md)。

页面布局、表单、弹窗与手机交互的检查结果见 [前端页面审查](docs/前端页面审查与修正.md)。

按最新功能需求与教师任务易用性的逐项验收、保存恢复修正及尚未接入的能力，见 [功能需求与易用性审查](docs/功能需求与易用性审查.md)。当前产品合同见 [产品说明](PRODUCT.md)。

## 运行

需要 Node.js 24，所有命令在本目录执行。

```bash
npm install
npm run dev
```

打开 [教学工坊本地预览](http://127.0.0.1:5173/#/home)。服务只监听 `127.0.0.1`，前端与原 API 共用 5173 端口。

```bash
npm test
npm run build
npm run test:e2e
```

新 Demo 的浏览器验收：`npx playwright test --config tests/skill-demo.config.ts`。可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE` 使用现有 Chromium，或用 `SKILL_DEMO_URL` 指定预览地址。只运行静态前端可使用 `npx vite --host 127.0.0.1 --port 5173`，不会启动 Express 或数据库。

运行 E2E 时保持开发服务器运行，浏览器使用本机 Chrome。测试覆盖教学方法创建、就地修改与重新核对、集市、独立探究成果、保存恢复、方法应用配置、学生预览提交和手机布局。

## 实现边界

当前界面不调用真实 LLM 或新增后端服务。方法内容核对、固定对话表达与规则模拟明确区分，不生成虚构的运行统计、异常结论或教学效果。检测与发布均为 Demo：演示通过不能代替真实模型验证，发布只加入本机集市。本机分享不会改变运行状态或上传到公共平台。数据保存于浏览器 localStorage，没有真实学生账户或跨设备同步。

原有 Express、SQLite、认证和模型适配代码保留，后续可按明确授权继续接入。
