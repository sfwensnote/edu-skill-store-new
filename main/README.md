# 教学工坊

让教师的教学经验成为可复用的智能教学能力。

客户演示版本包含日常教学、情境探究、教学 SKILL 集市、我的作品和教学任务。教学方法通过六轮互动追问与教师修订形成 SKILL，直接进入方法核对与学生视角预览；情境题、任务链和 PBL 作为独立作品编辑保存。教学任务只管理布置给学生的探究作品，可保存草稿、打开学生预览和查看本机记录。SKILL 应用配置在我的作品中管理，不混入学生任务。

最新流程、需求逐项核验和交互证据见 [流程简化与需求核验](docs/流程简化与需求核验.md)。任务与方法的关系见 [教学任务与 SKILL 应用](docs/教学活动创建说明.md)。此前的逻辑审查记录见 [项目逻辑审查](docs/项目逻辑审查与修正.md)。

页面布局、表单、弹窗与手机交互的检查结果见 [前端页面审查](docs/前端页面审查与修正.md)。

按最新功能需求与教师任务易用性的逐项验收、保存恢复修正及尚未接入的能力，见 [功能需求与易用性审查](docs/功能需求与易用性审查.md)。当前产品合同见 [产品说明](PRODUCT.md)。

面向客户演示的逐页操作路线、可直接填写的教学案例，以及模拟与真实能力的边界，见[全功能演示脚本](docs/全功能Demo演示脚本.md)。

最新「我的作品」页面、修改清单与验收结果见 [我的作品重构说明](docs/我的作品重构说明.md)。集市与导航的实现见 [SKILL 集市与导航调整说明](docs/SKILL集市与导航调整说明.md)。此前的规范与实现记录见 [全站 UI/UX 重构说明](docs/UIUX统一重构说明.md)和[客户演示版本说明](docs/教法集市升级说明.md)。[旧版项目详细说明](docs/项目详细说明.md)保留升级前的背景与实现记录。

## 运行

需要 Node.js 24，所有命令在本目录执行。

```bash
npm install
npm run dev
```

打开 [教学工坊本地预览](http://127.0.0.1:5173/#/home)。服务只监听 `127.0.0.1`，前端与原 API 共用 5173 端口。

```bash
npm test
npm run build
npm run test:e2e
```

运行 E2E 时保持开发服务器运行，浏览器使用本机 Chrome。测试覆盖教学方法创建、就地修改与重新核对、集市、独立探究成果、保存恢复、方法应用配置、学生预览提交和手机布局。

## 实现边界

当前界面不调用真实 LLM 或新增后端服务。方法内容核对、固定对话表达与规则模拟明确区分，不生成虚构的运行统计、异常结论或教学效果。未接入真实发布与 SKILL 启用能力，因此常用流程只提供保存和预览。本机分享不会改变运行状态或上传到公共平台。数据保存于浏览器 localStorage，没有真实学生账户或跨设备同步。

原有 Express、SQLite、认证和模型适配代码保留，后续可按明确授权继续接入。
